# spotiLator Development Skill

Use esta skill ao trabalhar neste repositorio.

## Passos obrigatorios

1. Leia `AGENTS.md`.
2. Leia `DOING.md`.
3. Leia `docs/status.md`.
4. Identifique uma tarefa pequena e dentro do escopo.
5. Preserve a separacao `Store`, `Query`, `Service`.
6. Rode `npm test`.
7. Atualize `docs/activity-log/README.md`.

## Regras de produto

- O app cataloga musicas romanticas e fontes de verificacao.
- Nao publique letras ou traducoes completas.
- Integracoes externas exigem fonte e contrato documentado.
- Prefira local-first e JSON exportavel.

## Sinais de parada

- Credencial externa necessaria e ausente.
- Decisao de produto nao documentada.
- Termos de uso de fonte de letra/traducao nao verificados.
